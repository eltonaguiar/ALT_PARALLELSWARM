# Output format — WT1_kilo-ernie-5.5-flash

Markdown, one file per topic under `files/`:

| File | Contents |
|------|----------|
| `shared_context.md` | Distilled vendor snippets (the context peers receive). |
| `01_discovery_config_options.md` | Configuration options catalog (table: property / where / effect / default). |
| `02_order_of_operations.md` | The four phases + ECC/MID Server mechanics, step by step. |
| `03_ci_class_manager.md` | CI Class Manager navigation + per-tab explanation. |
| `04_duplicate_avoidance_cmdb.md` | IRE identification/reconciliation, de-dup, insert vs update, properties. |
| `COMBINED_REPORT.md` | Assembled final report integrating WT2..WT5. |

Conventions:
- H2/H3 headings, tables for property catalogs.
- `[verify on instance]` marks anything needing a live check.
- Vendor URLs cited inline and in a Sources section.
