# Research corpus

75 markdown files extracted from the ServiceNow Zurich documentation on 2026-11-13,
plus `source_manifest.json` (URL + title for each) and two smoke-test notes.

Naming: `<map>__<topic-slug>.md`, where map is `itom` (ITOM Visibility/Discovery) or
`platcap` (ServiceNow AI Platform Capabilities: CMDB/IRE/CI Class Manager).

Each file starts with the source URL and release. Do not treat these as current for any
release other than Zurich; re-run the extraction recipe in `../00_PREREQ/PREREQ.md` for a
different family release.
