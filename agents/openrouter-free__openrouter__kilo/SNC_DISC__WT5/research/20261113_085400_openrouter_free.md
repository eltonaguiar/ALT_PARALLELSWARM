## Key findings

1. **Duplicate CMDB CI records** are created when the IRE can't find an existing CI.
2. **IRE decision tree:**
   - Payload → Validate → Loop identification rules → Query CMDB → CI found?
     - Yes: Is it active given inclusion rules? Yes: Reconciliation allows update? → Update; No → Do not update
     - No: Create new CI
3. **Domain separation**: Different domains with same Correlation ID = unique CIs.
4. **glide.discovery.multi_page_serial_mode=true** prevents duplicate creation from concurrent payloads.
